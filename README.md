# Mukanov Java QA Automation Task

Technical task for QA Automation traineeship

## Requirements

- Java 11 or later

## Task 1

The program:

1. Prints "Hello" to the console if the input number is greater than 7
2. Prints "Hello, John" to the console if the input name is John, prints "There is no such name" otherwise.
3. Outputs numbers that are multiples of three from a numerical array.

## Task 2

Given sequence: [((())()(())]]
The sequence is incorrect.
To make it correct, the first ] at the end should be replaced with ).
Correct sequence: [((())()(()))]

## Running the program

Compile with:
```bash
javac src/Main.java
```
Run with:
```bash
java -cp src Main
```
